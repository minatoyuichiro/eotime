# 図の縦軸の定義（1 つは何の 1 つか）

横軸はすべて「時間誤差 x」= パルス長の誤差を SWAP 時間 π/J で割った無次元量。
系統・乗法 ε: t→t(1+ε)。系統・加法 δ: t→t+δ。揺らぎ σ: パルスごとに独立な正規乱数（加法／乗法）、100 または 40 回の平均。

## gate_errors.png — ゲート単位
縦軸: 不忠実度 1 − |tr(U†A)|²/d²（実線）と漏れ 1 − tr(A†A)/d（点線）。A は物理操作の符号空間への射影ブロック。

## depth_scaling.png — 深さスケーリング
縦軸: 状態不忠実度 1 − |⟨ψ_ideal|ψ⟩|²（漏れ込み）。横軸: 回路のパルス数 N。誤差は ε=σ=1e-3 固定。

## qpe_shift.png — 離散の指標ではなく「平均推定位相」
縦軸: QPE 出力分布の円平均位相（φ=0.3 を推定）。系統誤差 ε に対して一方向にずれる。

## prefactor_vs_pulses.png
縦軸: 小誤差領域で誤差 = a·x² と置いたときの a（x ≤ 3e-3 の中央値）。1 次項がある対象では a は過大評価になる（summary.md の 1 次／2 次分離表を参照）。

## 揺らぎの点の統計誤差
揺らぎは平均 0 なので 1 次項は期待値では消えるが、有限回（40〜100 回）の平均には |b|·σ/√N の残りが乗る。
1 次項がある対象（QAOA p=1、Grover）の σ ≤ 1e-3 の点は、符号を含めてこの統計誤差（相対 P(opt) で 1e-4 程度）の中にある。
